## State15 相对原论文 LAM^CORE 的生物学差异

### 一、State15 中相对更高 / 更突出的特征

| 生物学特征 | State15 相对 LAM^CORE |
|---|---|
| **子宫样发育程序** | 更突出 |
| **HOXA11 / EMX2 相关特征** | 更突出 |
| **平滑肌 / 肌生成程序** | 更突出、更集中 |
| **收缩程序** | 更突出 |
| **ECM 重塑** | 更突出 |
| **MMP11 相关基质重塑** | 更突出 |
| **PLAT / SFRP1 等组织重塑特征** | 更突出 |

State15 的表达特征主要集中于：

**HOXA11 / EMX2 → uterine-like → myogenic / contractile → ECM remodeling**

代表性差异基因包括：

- HOXA11
- EMX2
- MMP11
- PLAT
- SFRP1
- PAGE4
- HTN3

---

### 二、State15 中相对更低 / 不突出的特征

| 生物学特征 | State15 相对 LAM^CORE |
|---|---|
| **PMEL / MLANA / MITF 等黑色素细胞样程序** | 较低 / 不突出 |
| **TYR / DCT 等 melanocytic 特征** | 较低 / 不突出 |
| **VEGFD 相关特征** | 较低 / 不突出 |
| **淋巴管生成相关程序** | 较低 / 不突出 |
| **ESR1 / PGR 等激素相关程序** | 较低 / 不突出 |
| **PCP4 / UNC5D / KCNAB1 等 neural-like 程序** | 较低 / 不突出 |
| **PITX2 / TWIST1 等 neural / developmental 特征** | 较低 / 不突出 |
| **广泛分泌 / secretome 特征** | 相对不突出 |
