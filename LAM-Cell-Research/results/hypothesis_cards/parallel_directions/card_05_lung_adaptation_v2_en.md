# Hypothesis Card 05 (revised): acquired pulmonary program

## Four-group comparison

The analysis uses normal uterus, LAM uterus, normal lung and pulmonary LAM, with:

```text
lung-acquired interaction =
(pulmonary LAM - normal lung) - (LAM uterus - normal uterus)
```

## Current observation

The lung-adaptation program remains a lung-acquired candidate. ECM interaction is increased in both LAM uterus and pulmonary LAM, making it more consistent with LAM transformation/lineage-associated disease than a purely lung-acquired program.

## Interpretation boundary

The four groups are not patient matched, and each uterus group currently has one source specimen. The interaction is descriptive population-level evidence, not an within-patient causal estimate.

## Current level

Exploratory hypothesis. More uterus donors, formal human–mouse orthology, independent pulmonary LAM donors and ATAC/spatial support are required.

## QC robustness

The fixed global sensitivity check contains 140 baseline candidates and 85 strict-QC candidates; LAM1/2/3/4 are 31/4/84/21 versus 28/1/52/4. The four-group interaction has not yet been rerun separately on both candidate pools, so this result remains exploratory.
