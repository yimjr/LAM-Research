# Translation hypotheses

这里记录由 GSE277844 translation program 与 GSE179044 residual 对照产生的机制假说。

每张假说卡应至少说明：

- 具体基因或稳定模块；
- 属于 plastic residual、hydrogel residual 还是二者都支持；
- GSE277844 的 translation 方向和效应量；
- RMC-6272/eFT-508 的处理后方向、距离变化和限制；
- 是否需要独立的药理或 CRISPR/shRNA 验证。

本目录不放大型矩阵；结构化结果位于 `data/processed/translation_analysis/`，正式总结位于 `reports/07_translation_analysis/`。
